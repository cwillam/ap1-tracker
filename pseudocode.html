Pseudocode verstehen – Von Null auf Prüfungsniveau

In der Abschlussprüfung Teil 1 geht es nicht um Programmiersprachen-Syntax, sondern um logisches Denken, Ablaufpläne und Schreibtischtests. Hier findest du alle Grundlagen verständlich erklärt – auch wenn du noch nie programmiert hast.

Was ist eigentlich Pseudocode & ein Algorithmus?

Ein Algorithmus ist nichts anderes als ein Kochrezept: Eine eindeutige Schritt-für-Schritt-Anleitung zur Lösung eines Problems. Pseudocode ist eine Mischung aus deutscher Sprache und Programmierbefehlen. Er ist absichtlich unabhängig von Java, Python oder C#, damit jeder Mensch den Ablauf sofort versteht.

1

Variablen, Zuweisung & Datentypen

Eine Variable ist wie eine beschriftete Kiste im Speicher. Mit = oder ← legst du einen Wert hinein.

// Die 4 wichtigsten Datentypen in Prüfungen:
GANZZAHL alter = 21 // Ganzzahl (Integer)
KOMMAZAHL preis = 19.99 // Fließkomma (Float/Double)
TEXT status = "In Prüfung" // Zeichenkette (String)
BOOLEAN istGueltig = WAHR // Wahrheitswert (WAHR / FALSCH)
Vorsicht: = weist zu, == vergleicht zwei Werte!
2

Bedingungen & Verzweigungen (WENN / DANN)

Entscheidungspfade im Code. Der Codeblock wird nur ausgeführt, wenn die Bedingung WAHR ergibt.

WENN punkte >= 50 DANN
ergebnis = "Bestanden"
SONST WENN punkte >= 30 DANN
ergebnis = "Mündliche Nachprüfung"
SONST
ergebnis = "Nicht bestanden"
ENDE WENN
Logische Operatoren: UND, ODER, NICHT.
3

Die 3 Schleifenarten im direkten Vergleich

Klassische Prüfungsfrage: „Wann nutzt man welche Schleife?“

100% Prüfungsrelevant
Zählschleife (FÜR) Feste Anzahl

Nutzt du, wenn die Anzahl der Wiederholungen vorher genau feststeht (z. B. jedes Element eines 10-teiligen Arrays durchlaufen).

FÜR i = 0 BIS 4 SCHRITT 1
drucke(i)
ENDE FÜR
Laufzeiten: Genau 5-mal (i nimmt die Werte 0, 1, 2, 3, 4 an).
Kopfgesteuert (SOLANGE) 0 bis n mal

Die Bedingung wird VOR dem ersten Betreten geprüft. Wenn sie anfangs falsch ist, läuft die Schleife überhaupt nicht (0-mal)!

SOLANGE energie > 0 TUE
energie = energie - 10
ENDE SOLANGE
Merke: Wird abgebrochen, sobald Bedingung FALSCH wird.
Fußgesteuert (WIEDERHOLE) Mindestens 1-mal

Die Prüfung erfolgt am Ende. Der Code wird garantiert mindestens 1-mal ausgeführt (z. B. Passwort-Abfrage im Terminal).

WIEDERHOLE
pin = liesEingabe()
BIS pin == 1234
Achtung: Bei BIS bricht die Schleife ab, sobald die Bedingung WAHR ist.
4

Die 3 Standard-Algorithmen der AP1 (Schritt für Schritt)

Diese Logiken musst du in der Prüfung im Schlaf aufschreiben können.

1. Lineare Suche
Suche nach Nadel im Heuhaufen

Läuft von Index 0 bis zum Ende. Sobald das gesuchte Element gefunden wird, wird der Index zurückgegeben. Ist das Ende erreicht, Rückgabe -1.

FÜR i = 0 BIS länge - 1
WENN arr[i] == ziel DANN
RÜCKGABE i
RÜCKGABE -1
2. Minimum & Index finden
Kleinstes Element ermitteln

Nimm das 1. Element als vorläufiges Minimum. Gehe durch den Rest. Ist ein Element kleiner, wird es das neue Minimum.

minWert = arr[0], minIdx = 0
FÜR i = 1 BIS länge - 1
WENN arr[i] < minWert DANN
minWert = arr[i], minIdx = i
RÜCKGABE minIdx
3. Bubble Sort
Wie Luftblasen nach oben steigen

Vergleicht Nachbar-Paare arr[j] und arr[j+1]. Ist das linke größer als das rechte, werden sie getauscht. Nach jedem Durchlauf ist die größte Zahl hinten.

WENN arr[j] > arr[j + 1] DANN
temp = arr[j]
arr[j] = arr[j + 1]
arr[j + 1] = temp

Die 5 goldenen Regeln für fehlerfreie Schreibtischtests in der Prüfung

1. Sei die CPU: Denke niemals voraus! Führe strikt nur die Zeile aus, auf der der Zeiger gerade steht.
2. Startzustand immer notieren: Schreibe vor der ersten Schleife die Anfangswerte aller Variablen auf.
3. Bedingungen separat protokollieren: Notiere dir Spalten für z. B. i < 5 (WAHR/FALSCH).
4. Array-Indizes bei 0 starten: Der häufigste Fehler ist, bei 1 anzufangen.
5. Schleifenende beachten: Erhöhe den Zähler erst am Ende des Durchlaufs vor der nächsten Bedingungsprüfung!
