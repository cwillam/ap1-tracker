Pseudocode verstehen – Logik & Schreibtischtests

In der IHK-Abschlussprüfung Teil 1 geht es nicht um Programmiersprachen-Syntax, sondern um Ablauflogik, Datenstrukturen und deterministische Schreibtischtests. Hier findest du alle prüfungsrelevanten Kernkonzepte auf den Punkt gebracht.

Was ist eigentlich Pseudocode & ein Algorithmus?

Ein Algorithmus ist eine eindeutige, endliche Schritt-für-Schritt-Vorschrift zur Lösung eines Problems. Pseudocode ist eine abstrahierte Notation aus natürlicher Sprache und standardisierten Steuerstrukturen. Er ist unabhängig von konkreten Sprachen (weder reines Python, Java noch C#), damit der Prüfling den logischen Ablauf ohne syntaktische Sprachhürden modellieren und nachvollziehen kann.

1

Variablen, Zuweisung & Datentypen

Eine Variable reserviert Speicherplatz für einen Wert. Mit = oder ← erfolgt die Zuweisung.

// Die 4 wichtigsten Datentypen in Prüfungen:
GANZZAHL alter = 21 // Ganzzahl (Integer)
KOMMAZAHL preis = 19.99 // Fließkomma (Float/Double)
TEXT status = "In Prüfung" // Zeichenkette (String)
BOOLEAN istGueltig = WAHR // Wahrheitswert (WAHR / FALSCH)
Vorsicht in Klausuren: = weist zu, == vergleicht zwei Werte!
2

Bedingungen & Verzweigungen (WENN / DANN)

Verzweigungen steuern den Kontrollfluss. Ein Block wird nur ausgeführt, wenn der logische Ausdruck zu WAHR evaluiert.

WENN punkte >= 50 DANN
ergebnis = "Bestanden"
SONST WENN punkte >= 30 DANN
ergebnis = "Mündliche Ergänzungsprüfung"
SONST
ergebnis = "Nicht bestanden"
ENDE WENN
Boolesche Operatoren: UND, ODER, NICHT.
3

Die 3 Schleifenarten im direkten Vergleich

Klassische IHK-Prüfungsfrage: „Welche Schleifenart ist hier die richtige?“

100% Prüfungsrelevant
Zählschleife (FÜR) Feste Anzahl

Verwenden, wenn die Anzahl der Durchläufe vorab exakt bekannt ist (z. B. Iteration über Array-Indizes).

FÜR i = 0 BIS 4 SCHRITT 1
drucke(i)
ENDE FÜR
Laufzeiten: Genau 5-mal (i durchläuft 0, 1, 2, 3, 4).
Kopfgesteuert (SOLANGE) 0 bis n mal

Prüfung erfolgt VOR dem Betreten. Ist die Bedingung anfangs unwahr, läuft die Schleife 0-mal (abweisend).

SOLANGE energie > 0 TUE
energie = energie - 10
ENDE SOLANGE
Merke: Bricht ab, sobald die Bedingung FALSCH wird.
Fußgesteuert (WIEDERHOLE) Mindestens 1-mal

Prüfung erfolgt am Ende. Der Rumpf wird garantiert mindestens 1-mal ausgeführt (z. B. Benutzereingabe validieren).

WIEDERHOLE
pin = liesEingabe()
BIS pin == 1234
Achtung: Bei BIS bricht die Schleife ab, sobald Bedingung WAHR ist.

Die 3 Standard-Algorithmen der AP1

Kernmuster für Sortierung und Suche in den Abschlussprüfungen

1. Lineare Suche
Element in unsortiertem Array finden

Iteriert von Index 0 bis Ende. Bei Treffer sofortige Rückgabe des Index i. Wenn Schleife ohne Treffer durchläuft: -1.

FÜR i = 0 BIS länge - 1
WENN arr[i] == ziel DANN
RÜCKGABE i
RÜCKGABE -1
2. Minimum & Index finden
Kleinsten Wert im Feld ermitteln

Setze erstes Element als vorläufiges Minimum. Prüfe alle Folgeelemente. Ist ein Element kleiner, aktualisiere Minimum und Index.

minWert = arr[0], minIdx = 0
FÜR i = 1 BIS länge - 1
WENN arr[i] < minWert DANN
minWert = arr[i], minIdx = i
RÜCKGABE minIdx
3. Bubble Sort
Benachbarte Elemente vertauschen

Vergleicht Nachbar-Paare arr[j] und arr[j+1]. Ist das linke größer, wird über Hilfsvariable getauscht (Swap).

WENN arr[j] > arr[j + 1] DANN
temp = arr[j]
arr[j] = arr[j + 1]
arr[j + 1] = temp

Die 5 goldenen Regeln für fehlerfreie Schreibtischtests

1. Sei die CPU Denke niemals voraus! Führe strikt nur die Zeile aus, auf der der Zeiger aktuell steht.
2. Startzustand protokollieren Schreibe vor Eintritt in die erste Schleife alle Initialwerte der Variablen auf.
3. Array-Indizes bei 0 starten Der häufigste Flüchtigkeitsfehler in Prüfungen ist der Beginn bei Index 1.
4. Bedingungen protokollieren Halte Schleifen- und Verzweigungsbedingungen als WAHR / FALSCH schriftlich fest.
5. Inkrementierung am Schleifenende beachten Zähler werden typischerweise am Ende des Schleifendurchlaufs inkrementiert, unmittelbar vor der nächsten Bedingungsprüfung!
